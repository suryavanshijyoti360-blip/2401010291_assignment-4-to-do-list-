## Advanced To-Do List Application

This project is a functional, browser-based task management tool developed using a clean stack of HTML5, CSS3, and vanilla JavaScript. The application allows users to create, read, update, and delete tasks locally, featuring a modern dark-mode interface optimized for clarity and focus. To ensure a seamless user experience, it utilizes the Web Storage API (localStorage) to persist data across browser sessions, preventing task loss upon page refreshes.

The logic is built around dynamic DOM manipulation and event-driven programming, handling real-time list updates without external dependencies. Beyond basic task entry, the app automatically timestamps each entry and provides interactive controls for marking tasks as complete, editing existing text, or removing items from the list. The CSS implementation leverages Flexbox for a responsive, centered layout, making it a robust example of a CRUD application contained within a single, lightweight file.
